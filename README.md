# artifact-server

Hosts and shares artifacts generated by an AI plugin system. Two jobs: upload one or
more files, fetch them back by URL.

## Run

```bash
npm install
npm run dev     # prints the LAN URL, e.g. http://192.168.1.42:3000
```

| Env | Default | Purpose |
|---|---|---|
| `BASE_URL` | this machine's LAN address, e.g. `http://192.168.1.42:3000` | Prefix for returned share URLs |
| `TTL_HOURS` | `24` | How long artifacts live |

## API

### `POST /artifacts`

`multipart/form-data`, one or more files under the field name **`files`**.
Returns an opaque bundle id and a share URL per file.

```json
{
  "id": "bba1a30b-56e9-45ef-bc1b-95cb0b6c724d",
  "urls": ["http://192.168.1.42:3000/artifacts/bba1a30b-.../index.html"]
}
```

No files under `files` → `400`.

### `GET /artifacts/:id`

Lists the files in a bundle. Unknown id → `404`.

### `GET /artifacts/:id/:name`

Serves the file with a content-type inferred from its extension, so uploaded HTML
renders in a browser. Unknown file → `404`.

## Clients

Plugin (Node 18+):

```ts
const fd = new FormData();
fd.append("files", new Blob([html], { type: "text/html" }), "index.html");
const { urls } = await (await fetch(`${BASE}/artifacts`, { method: "POST", body: fd })).json();
```

curl:

```bash
curl -X POST localhost:3000/artifacts -F 'files=@index.html' -F 'files=@style.css'
```

Postman: Body → **form-data** (not **binary**, which is where the octet-stream-only
restriction comes from). Key `files`, hover the key cell and switch the **Text/File**
dropdown to **File**. Repeat the `files` row per file. Do not set `Content-Type`
yourself — Postman has to generate the multipart boundary.

## MCP server

`mcp.ts` is a stdio MCP server that lets an agent use the HTTP server above. Run
it on the agent's machine. It needs the HTTP server running somewhere it can reach.

| Tool | Input | Does |
|---|---|---|
| `generate` | `paths: string[]` | Uploads local files as one bundle, returns `{ id, urls }` |
| `pull` | `ref` (bundle id or share URL), optional `dir` | Downloads every file in the bundle to `dir` (default `./.artifacts/<id>`) |

If `ref` is a full URL, `pull` downloads from that URL's host. Everything else uses
`ARTIFACT_SERVER_URL` (default `http://localhost:3000`).

Cursor (`.cursor/mcp.json`) / Claude Desktop config:

```json
{
  "mcpServers": {
    "artifacts": {
      "command": "npx",
      "args": ["tsx", "/abs/path/to/artifact-server/mcp.ts"],
      "env": { "ARTIFACT_SERVER_URL": "http://192.168.1.42:3000" }
    }
  }
}
```

## Storage & expiry

Files land in `artifacts/<uuid>/<filename>`. A sweep on startup and hourly thereafter
deletes bundles whose mtime is older than `TTL_HOURS`.

## Scope

Hackathon build. Uploads are **open** — no auth. The UUID in the path is the only
access control: links are unguessable, but anyone holding one can read the artifact.

Deliberately skipped, add when needed:

- auth / upload tokens — when uploads need to be attributed or restricted
- metadata DB — when you need to list, search, or own artifacts
- S3 or similar — when it outgrows one machine's disk
- raw-body `PUT` endpoint — if a client can't send multipart
